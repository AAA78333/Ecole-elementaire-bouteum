# Ecole élémentaire Boutum

This project is a small static school website with a landing page and a login page.

## Files
- `index.html` – homepage for the elementary school
- `login.htm` – login page for parents and staff
- `styles.css` – shared styling for both pages
- `file.jpe` – placeholder school image

## Run locally
From this repository root, start a simple local server:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000` in your browser.
